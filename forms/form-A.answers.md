## 자기보고 대조 (플래그 확정)

| 자기보고 | 뒷받침 기준 | 적용 축 |
|---|---|---|
| SR-1 결과물 개수 | `3~4개` 이상 = 뒷받침 / `0개` = 상충 | DSN, VER |
| SR-2 없어진 업무 | `있다`(내용 기재) = 뒷받침 | FLW |
| SR-3 잘 쓰는 사람 | `1명` 이상 = 뒷받침 | FLW |

불일치 시 플래그를 **판정 보류로 하향**한다. DEL·RSK는 대응 자기보고가 없으므로 MC 플래그를 그대로 쓴다. 정본은 [docs/04-scoring.md](../docs/04-scoring.md).

## 총점과 레벨

```
총점 = 객관식 득점(최대 60) + FR-01(최대 20) + FR-02(최대 20)
```

| 레벨 | 점수 | 이름 |
|---|---|---|
| L1 | 0–39 | 미착수 |
| L2 | 40–59 | 개인 활용 |
| L3 | 60–79 | 업무 내재화 |
| L4 | 80–100 | 재설계자 |

**총점은 ±5점 밴드로만 해석한다.** 경계(39/40, 59/60, 79/80)에 걸친 응시자는 "L2~L3 경계"로 표기하고 **낮은 쪽 처방**을 적용한다.

## 오답 진단 참조

리포트의 서술 피드백을 쓸 때는 응시자가 고른 오답의 `distractor_dx`를 그대로 인용한다. 각 문항 파일의 frontmatter와 「오답 진단」 절에 있다.

특히 아래 두 오답은 **처방이 다르므로 반드시 구분해 기록한다**.

| 오답 | 진단 | 처방 |
|---|---|---|
| 1번 선택지 3 / 13번 선택지 3 / 21번 D1 상한 | **겉보기 human-in-the-loop** — AI가 정한 선택지 집합에서 고르는 것을 판단으로 착각 | 위임 구조 자체를 바꿔야 함 |
| 9번 선택지 1 / 5번 선택지 1 | **덧붙이기** — 기존 단계에 AI를 얹고 흐름은 그대로 | 단계 소멸 관점 교육 |

## 채점 절차

정본은 [docs/04-scoring.md](../docs/04-scoring.md)의 채점 절차. 요약:

1. 객관식 대조 → 부분 점수 적용
2. 축별 정답 수 → 3단 플래그
3. 자기보고 대조 → 플래그 확정
4. 앵커 캘리브레이션 → 주관식 LLM 채점(차원별 독립 4패스 + 감점 1패스)
5. 인간 20% 표본 재채점 → 2점 이상 불일치는 인간 판정 채택 + 앵커 보강
6. 총점 → 레벨(경계는 낮은 쪽)
7. 리포트 생성 → 필수 문구 삽입 확인, **금지 표현 검사**(축별 점수·백분위·레이더 없음)
8. 처방 매핑 → [docs/06-prescription.md](../docs/06-prescription.md)
