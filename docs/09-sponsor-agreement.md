# 09. 스폰서 합의문

> **이 문서에 서명이 없으면 진단을 시행하지 않는다.**

## 왜 진단 전에 서명하는가

이 진단이 실패하는 가장 큰 방식은 문항이 틀리는 것이 아니다. **결과가 리포트 한 장으로 끝나는 것**이다.

조사에 따르면 역량 진단이 필요하다고 느끼는 조직은 많지만(51.5%가 "방법을 모른다"), 진단 결과를 실제로 교육 설계에 반영한 조직은 **3.6%**다. 그리고 역량 진단 후 수준별로 설계한 교육조차 32%만 성공하는데, 실패하는 68%의 원인은 ① 경영진 리스크 ② 출구 전략 부재 — **둘 다 문항 품질로는 해결되지 않는다.**

그래서 처방을 진단 *후* 산출물이 아니라 진단 *전* 합의문으로 만든다. 비용은 이 문서 1장과 미팅 1회다.

## 합의 사항

**조직**: ______________________  **부서/대상**: ______________________  **예상 응시 인원**: ______명

**스폰서(의사결정권자)**: ______________________ (직책: ____________)
**실무 책임자**: ______________________ (직책: ____________)
**시행 예정일**: ________________

---

### 1. 이 결과로 실제로 바꿀 것 2개

추상적으로 쓰지 않는다. **이름까지** 적는다.

**(1) 편성할 교육 트랙 1개**

> 예: "검증·신뢰 조정 축 보완 필요 인원을 모아 '데이터 검증 실무' 4시간 과정을 10월 3주에 2차수 편성한다"

```
편성할 트랙:
대상 선정 기준:
차수·일정:
```

**(2) 변경할 업무 프로세스 1개**

> 예: "주간 부서보고 통합 업무에서 '5개 부서 양식 수동 정리' 단계를 없애고, 부서 제출 양식을 통일한다"

```
대상 업무:
없앨/바꿀 단계:
변경 책임 부서:
```

### 2. 결과의 인사 반영 여부

[헌장의 2트랙 정책](00-charter.md)에 따라 **하나만** 선택한다. 둘을 겸할 수 없다.

- [ ] **ⓐ 진단 회차** — 무기명/가명, 교육 설계 전용, **인사 미반영**. 축 플래그와 조직 리포트를 산출한다. *(본 문항 뱅크가 지원하는 유일한 방식)*
- [ ] **ⓑ 인증 회차** — 기명, 총점·주관식을 인사에 반영. **별도 문항풀을 새로 만들어야 하며 본 뱅크를 쓸 수 없다.** 축 플래그는 산출하지 않는다.

ⓐ를 선택한 경우, 아래 문장을 시행 안내문에 그대로 넣는 데 동의한다.

> 이 진단의 결과는 교육 설계에만 사용되며, 인사 평가·승진·배치 자료로 사용되지 않습니다.

스폰서 동의: [ ] 예

### 3. 진단 후 4주 내 후속 조치

| 시점 | 할 일 | 책임자 (실명) |
|---|---|---|
| D+1주 | 채점 완료, 조직 리포트 생성 | |
| D+2주 | 리포트 공유 및 트랙 편성 확정 | |
| D+3주 | 대상자 통보, 프로세스 변경 착수 | |
| D+4주 | 1차 교육 개강 | |

**책임자 칸이 비어 있으면 합의문은 무효다.** "HRD팀"이 아니라 사람 이름을 적는다.

### 4. 재진단과 비교 지표

**재진단 일자**: ________________ (권장: 교육 종료 후 8~12주)

비교할 지표를 고른다. **총점 상승을 주 지표로 쓰지 않는다** — 시간 절감만 보고하면 경영진이 "남는 시간에 뭐 했냐"고 묻고, 그 자리에서 보고가 멈춘다.

- [ ] AI 때문에 **사라진 업무 단계** 건수
- [ ] 절감 시간의 **전환처** (어떤 업무로 옮겼는지)
- [ ] 워크플로우 재설계 축의 **보완 필요 비율** 감소
- [ ] 축별 **편차**(구성원 간 수준 차이) 감소
- [ ] 기타: ______________________

### 5. 시행 조건 확인

- [ ] 응시자에게 35분의 업무 시간을 보장한다 (자율 응시로 돌리지 않는다)
- [ ] 무기명을 약속한 경우, 응답 원본을 인사 부서에 전달하지 않는다
- [ ] 조직 리포트는 n≥10, 표의 개별 셀은 n≥5에서만 생성한다는 제약을 이해한다
- [ ] 축별 결과는 점수가 아니라 3단 플래그로만 제공된다는 제약을 이해한다 ([근거](04-scoring.md))
