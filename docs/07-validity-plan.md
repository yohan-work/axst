문항 뱅크는 실행 가능한 코드가 아니므로 **린트 → 자가 응시 → 파일럿** 3단으로 검증한다. 1단은 완료(자동화), 2단은 채점 리허설만 완료했고 소요 시간 실측이 남았다. 3단은 실행 계획이다.

### 초기 린트에서 잡힌 것

선택지 길이 비율 위반 5건(`MC-DEL-003` `MC-DSN-004` `MC-VER-003` `MC-VER-004` `MC-VER-005`). **그중 4건은 정답이 가장 긴 선택지**여서 실제 길이 단서로 작동했을 것이다. 의미를 바꾸지 않고 다른 선택지를 늘리거나 정답을 줄여 비율을 1.14 이하로 맞췄다. 이 검사가 육안으로는 잡히지 않는 유형이므로 자동화 가치가 가장 크다.

## 3단: 파일럿

### 규모와 대상

| 항목 | 값 |
|---|---|
| 인원 | **10~15명** |
| 대상 | **IT 기업의 비개발 사무직**(기획·PM·운영·마케팅·영업·CS·인사·재무). 개발자는 넣지 않는다 — [00-charter.md](00-charter.md#검증-집단을-이렇게-정한-이유-2026-09-22-결정) |
| 선행 | [정답 키 검토](15-key-review.md) — AI 패널 → 전문가 패널. 키가 검증되지 않은 채 사람을 재면, 점수가 역량인지 출제자와의 일치도인지 가를 수 없다 |
| 주관식 채점 | 파일럿에서는 **사람이 전부 채점**한다(`pilot.py sample --rate 1.0`). 20% 표본이면 약 5건이라 1건만 어긋나도 관문 B 4번(불일치 < 20%)이 뒤집힌다 |
| 구성 | 레벨이 섞이도록 의도적으로 선정 — AI를 거의 안 쓰는 사람 3~4명, 활발히 쓰는 사람 3~4명, 나머지 중간 |
| 방식 | 실제 시행과 동일하게 35분 타임박스, 무기명 |
| 사전 안내 | [08-administration.md](08-administration.md)의 사전 안내자료를 그대로 제공 (우선순위 규칙 공개 포함) |

**왜 레벨을 섞어 선정하나**: 변별도(`d`)는 상위 27%와 하위 27%의 정답률 차이로 계산한다. 응시자가 동질적이면 변별도가 구조적으로 낮게 나와 좋은 문항을 잘못 폐기하게 된다.

**n=10~15의 한계를 명시한다.** 이 표본으로는 정답률(`p`)의 대략적 위치와 명백히 망가진 문항만 잡을 수 있다. 변별도는 참고 수준이다. 축별 평균이나 레벨 분포는 이 단계에서 해석하지 않는다.

### 문항 분석 지표

| 지표 | 계산 | 목표 |
|---|---|---|
| 정답률 `p` | 정답자 수 / 응시자 수 | 0.30 ~ 0.80 |
| 변별도 `d` | 상위 27% 정답률 − 하위 27% 정답률 | ≥ 0.20 |
| 오답 선택률 | 각 오답을 고른 비율 | 모든 오답 > 0% |

**최선–최악 문항**은 최선 정답률과 최악 정답률을 따로 계산한다.

### 폐기·수정 기준

| 조건 | 조치 |
|---|---|
| `p < 0.25` | `status: 보류`. 정답 오류·지문 결함을 먼저 확인한 뒤 판단 |
| `p > 0.90` | `status: 보류`. 변별이 안 됨 |
| `d < 0.20` | `status: 보류`. **1축 변화 원칙 위반을 의심한다** — 선택지가 여러 차원에서 동시에 달라졌을 가능성 |
| 오답 선택률 0% | 문항 유지, **그 오답만 재작성**. 필러 오답은 실질적으로 3지선다를 만든다 |

보류 문항은 **예비 4문항**(`MC-DEL-005` `MC-VER-005` `MC-FLW-005` `MC-RSK-005`)으로 교체한다. 같은 축의 예비가 없으면(DSN) 새로 출제한다.

판단 근거는 전부 [pilot/item-analysis.md](../pilot/item-analysis.md)에 기록한다.

### 관문 B — 본 시행으로 갈지 ★

파일럿이 끝나면 `python3 scripts/pilot.py gate`로 판정한다. **기준은 파일럿 전에 스폰서와 확인한다.** 결과를 보고 기준을 고르면 관문이 아니다.

| # | 기준 | 계산 | 통과 | 왜 |
|---|---|---|---|---|
| 1 | 소요 시간 | 온라인 응시본이 기록한 전체 소요가 35분 이내인 응답 비율 | **≥ 80%** | 35분 업무시간 보장이 본 시행의 전제다. 넘는 사람이 많으면 시간 배분부터 다시 짠다 |
| 2 | 주관식 미작성률 | 빈 답안 / (응답 × 2) | **< 20%** | [08](08-administration.md)의 시간 배분 재검토 기준과 같다 |
| 3 | 보류 후보 문항 | `p < 25%` 또는 `p > 90%`(최선–최악은 최악 정답률도) 또는 **`d < 0`** 인 문항 수 | **≤ 4** | 예비 4문항으로 교체할 수 있는 한도 |
| 4 | 사람–LLM 불일치 | 인간 표본 답안 중 어느 차원이든 2점 이상 또는 감점 판정이 다른 비율 | **< 20%** | 넘으면 LLM 채점을 본 시행에 쓸 수 없다 — 앵커 보강이나 사람 채점으로 간다 |
| 5 | 결과 분산 | 총점이 나온 응답의 레벨 종류 | **≥ 2종** | 한 레벨에 몰리면 반을 나눌 근거가 없다 — 진단을 도입할 이유가 사라진다 |
| 6 | 리포트 납득도 | 회신 중 "리포트가 내 실제 모습과 맞다" 4~5점 비율 (회신이 응답의 절반 이상일 때만) | **> 50%** | 받는 사람이 납득하지 않는 진단은 교육 편성 근거로 쓰이지 않는다 |

- **판정은 셋이다 — 통과 / 미달 / 판정 불가.** 기록이 없거나(지필 시간, 인간 표본 미실시, 납득도 미회신) 응답이 10명 미만이면 판정 불가다. 판정 불가가 남아 있으면 통과로 보지 않는다
- **3번에서 `d < 0.20`을 세지 않는 이유**: 위 폐기·수정 기준표는 `d < 0.20`을 보류로 보지만, n=10~15에서 상·하위 27%는 3~4명이라 한 명만 바뀌어도 `d`가 25~33%p 움직인다. 관문에서는 **음수(상위가 하위보다 더 틀림)만** 명백한 결함으로 센다. 상·하위 경계에 객관식 동점자가 걸리면 남은 자리를 동점자끼리 똑같이 나눠 갖는다 — 그러지 않으면 누가 그룹에 드는지가 파일 순서로 정해져 `d`가 우연히 음수가 된다. `d` 0~20% 문항은 `gate`가 참고로 보여 주고, 응시 후 설문의 "헷갈린 문항" 지목과 겹치면 수정 후보로 기록한다
- **미달이면 본 시행을 제안하지 않는다.** 원인과 조치를 [pilot/item-analysis.md](../pilot/item-analysis.md)에 적고, 조치 후 소규모로 다시 확인한다

**리포트 납득도는 응시 때가 아니라 리포트를 받은 뒤 묻는다.** 파일럿 개인 리포트 끝에 1~5 회신 요청이 들어 있고, 운영자는 회신을 `pilot/work/fit.csv`(`pilot.py reports`가 빈 칸으로 만든다)에 적는다.

### 응시 후 설문 (참고, 판정에 쓰지 않음)

온라인 응시본은 **제출 뒤·파일 저장 전**에 선택 질문 3개를 묻고 응답 파일의 `survey`에 담는다. 점수와 무관하고 응시 시간에 포함되지 않는다.

| 질문 | 쓰는 곳 |
|---|---|
| 헷갈려서 답을 고르기 어려웠던 문항 번호(여러 개)와 이유 | 문항 수정 후보. 합성 파일럿 S0에서 11·18번을 드러낸 신호인데, 그 전까지 실제 응시본은 이것을 받지 않았다 |
| 문항의 상황이 내 업무에서 있을 법했는가 (1~5) | 현업 적합성. 낮으면 문항이 아니라 지문 맥락을 먼저 본다 |
| 22번 페르소나 중 내 직무에 맞는 것이 있었는가 + 직무 | 페르소나 공백. 예: 웹 퍼블리싱처럼 6종에 없는 직무가 몰리는지 |

### 준거 타당도 프록시

준거 변인(실제 업무 성과)을 구할 수 없으므로 자기보고를 프록시로 쓴다. **이것은 타당도의 증명이 아니라 최소한의 반증 시도**다.

| 확인 | 기대 | 어긋나면 |
|---|---|---|
| SR-1(결과물 개수)이 높은 집단의 DSN·VER 평균 | 더 높음 | 문항이 실사용과 무관한 것을 재고 있을 가능성 → 문항 재검토 |
| SR-2(없어진 업무)가 있는 집단의 FLW 평균 | 더 높음 | FLW 문항이 흐름 재설계 경험을 못 잡고 있음 |
| SR-3(잘 쓰는 사람 인지)이 있는 집단의 총점 | 더 높음 | — |
| 자기보고는 높은데 총점이 낮은 응시자 | 소수 | **다수면 문항 타당도를 근본적으로 재검토한다.** 지필 SJT가 실제 역량을 못 잡고 있다는 신호이고, 이 경우 v2의 실제 LLM 수행 과제 경로를 앞당긴다 |

### 채점자 간 신뢰도 (IRR)

| 항목 | 기준 |
|---|---|
| 이중 채점 범위 | LLM 전수 + **인간 20% 표본** |
| 불일치 기준 | 어느 차원에서든 **2점 이상** |
| 불일치 시 | 인간 판정 채택 + 그 사례를 앵커 파일에 추가 |
| D1 재확인 | D1은 유일한 저신뢰 차원. 불일치가 표본의 30%를 넘으면 레벨당 앵커를 2개에서 3개로 늘린다 |
