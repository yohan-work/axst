# 13. 파일럿 제안서 (1쪽)

조직에 파일럿을 제안할 때 그대로 채워 쓰는 1쪽짜리 양식이다. 빈칸(`____`)만 채우면 된다. 근거 문서는 링크로만 붙이고 본문에 옮기지 않는다 — 결정권자는 1쪽만 읽는다.

---

## AX Literacy 진단 파일럿 제안

**제안자** ____ · **대상** ____ (____명) · **제안일** ____

### 무엇을 하나

구성원 **10~15명**이 **35분** 동안 AI 활용 판단력 진단(객관식 20 + 주관식 2)을 봅니다. 목적은 두 가지입니다.

1. **이 진단이 우리 조직에서 작동하는지 확인** — 문항이 우리 업무 맥락에서 이해되는지, 35분이면 충분한지, 결과가 사람마다 갈리는지
2. **AI 교육을 수준별로 나눌 근거 확보** — 지금처럼 전원에게 같은 교육을 하는 대신, 어떤 반을 몇 개 열어야 하는지 초안을 얻습니다

툴 지식(모델 이름, 기능 명칭)은 묻지 않습니다. **무엇을 AI에 맡기고, 결과를 어떻게 검증하고, 업무 흐름을 어떻게 바꾸는지**를 실제 업무 상황으로 묻습니다.

### 하지 않는 것

- **인사 평가·승진·배치에 쓰지 않습니다.** 파일럿 결과로 반 편성을 확정하지도 않습니다
- 개인별 축 점수, 백분위, 순위표를 만들지 않습니다
- 개인 리포트는 본인에게만 갑니다. 조직에는 5명 미만 칸을 가린 집계만 갑니다

### 무엇을 받나

| 받는 사람 | 산출물 | 샘플 |
|---|---|---|
| 참여자 본인 | 총점 구간·수준, 5개 축 신호, 주관식 피드백, 다음 행동 2개 | [개인 리포트 샘플](samples/report-individual.sample.html) |
| 제안 대상 조직 | 수준 분포, 축별 평균, 편차, 오답이 몰린 문항의 오개념, 코호트 편성 초안 | [조직 리포트 샘플](samples/report-org.sample.html) |
| 담당자 | 문항 검증 기록(문항별 정답률·오답 분포·실측 소요 시간), 본 시행 여부 판단 근거 | [문항 분석 기록](../pilot/item-analysis.md) |

> 샘플은 가상의 응답 12명으로 만든 예시입니다. 브라우저로 열어 인쇄할 수 있습니다.

### 일정 (약 4주)

| 주 | 할 일 | 필요한 것 |
|---|---|---|
| 1 | 스폰서 합의(1쪽 서명), 참여자 선정, 사전 안내 배포 | 결정권자 미팅 30분 |
| 2 | 응시 — 업무 시간 중 35분, 같은 날 일괄 | 참여자 35분 × ____명 |
| 3 | 채점(객관식 자동 · 주관식 LLM + 사람 표본 검토) | 사내 허용 LLM |
| 4 | 개인 리포트 전달, 조직 리포트 보고, 본 시행 여부 결정 | 보고 30분 |

### 조직에 요청하는 것

1. **스폰서 합의문 서명** — 결과로 실제로 바꿀 것 2개(교육 트랙 1개, 업무 프로세스 1개)를 미리 정합니다. 결과가 리포트 한 장으로 끝나지 않게 하려는 장치입니다 → [09-sponsor-agreement.md](09-sponsor-agreement.md)
2. **업무 시간 35분 보장** — 자율 응시로 돌리면 응시 조건이 사람마다 달라져 결과를 비교할 수 없습니다
3. **주관식 채점에 쓸 사내 허용 LLM** — 답안에 업무명·시스템명이 들어가므로 개인 계정의 외부 서비스는 쓰지 않습니다

### 개인정보

응답은 인터넷으로 전송되지 않고 참여자가 파일로 담당자에게 보냅니다. 채점 자료에는 이름 대신 번호만 쓰고, 응답 원본과 채점 파일은 **리포트 전달 2주 뒤 삭제**합니다. 조직 리포트만 재진단 기준선으로 보존합니다 → [08-administration.md](08-administration.md#응답-데이터-취급)

### 파일럿 뒤에

결과가 쓸 만하면 **본 시행**으로 넘어갑니다. 본 시행은 정답이 공개되지 않은 별도 문항지로 하고, 결과로 교육 반을 편성한 뒤 8~12주 후 재진단합니다. 이때 주 지표는 점수 상승이 아니라 **실제로 없어진 업무 건수**입니다 → [06-prescription.md](06-prescription.md#6-재진단)
