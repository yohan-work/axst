# 12. 열린 과제

검증 회차(C0 · C1 · S0)에서 나왔지만 아직 해결하지 않은 문제를 모았다. 결함 전문은 [10-calibration-findings.md](10-calibration-findings.md)와 [11-synthetic-pilot.md](11-synthetic-pilot.md)에 있고, 이 문서는 **무엇이 남았고 누가 결정해야 하는지**만 다룬다.

기여를 고민 중이라면 여기서 시작하면 된다. 다만 루브릭과 채점 규칙 변경은 진단 전체의 기준을 바꾸므로, **PR보다 이슈로 먼저 논의한다.**

---

결함 14·15·16·17과 S0-1~3은 **2026-09-17에 결정했다.** 근거와 독립 채점 검증은 [10-calibration-findings.md](10-calibration-findings.md) "루브릭 결정 (2026-09-17)".

남은 것:

| # | 문제 | 심각도 | 근거 |
|---|---|---|---|
| 결함 18 | D4 2점과 3점의 경계 — *"X하는 시간이 줄어든다"* 가 시간 절감(2)인지 단계 지목(3)인지 문구가 정하지 않는다. 3점 칸은 "줄어드는 단계"를 인정하는데 2점 예시는 "보고서 작성이 빨라진다"다 | 중간 | 같은 답안이 세 패스에서 2 / 4 / 2. 리허설 채점자가 **"업무 전체를 다시 부른 것인가, 하위 단계를 지목했는가"** 를 스스로 기준으로 썼다 — 해법 후보. 파일럿 응답에서 이 기준이 갈리는지 본 뒤 정한다 |

## C. 사람이 해야 하는 것

에이전트나 합성 응시자로 대체할 수 없다.

- **소요 시간 실측.** 온라인 응시본을 사람이 실제로 풀면 구간별 시간이 자동 기록된다. 현재는 추정치(32~35분)뿐이다.
- **스폰서 합의문 서명.** [09-sponsor-agreement.md](09-sponsor-agreement.md). 서명 없이 시행하지 않는다.
- **실제 파일럿 10~15명.** 레벨을 섞어 선정한다. 합성 파일럿 S0는 이것을 대체하지 못한다 — 정답률·변별도·시간은 사람에게서 다시 잰다.
- **독립 채점 검증.** 지금까지의 LLM 채점 검증은 같은 모델 계열 안에서 이뤄졌다. 인간 채점자 또는 다른 계열 모델과의 수렴 확인이 필요하다.
