| 지표 | 값 |

**이 항목이 조직 리포트에서 평균보다 중요하다.** IT 업종에서는 직원 간 AI 수준 차이가 도입 장벽 1위(55%)로 꼽힌다. 평균이 올라도 편차가 크면 팀 단위 적용이 되지 않고, 잘 쓰는 소수에게 일이 쏠린다.

## 5. 감점 발생률 (RSK 축 보조 지표)

| 감점 | 건수 | 비율 |
|---|---|---|
| −5 (민감 데이터 외부 투입 / 사외 무검증 게재) | | % |

**22번(FR-02)은 페르소나별로 나눈다.** 페르소나마다 위반할 기회가 달라서, 섞은 비율은 거버넌스가 아니라 페르소나 선택 분포를 반영한다([penalty-risk.md](../rubrics/penalty-risk.md) "조직 리포트에서의 취급").

| 22번 페르소나 | 응답 수 | −5 | −2 | 비율 |
|---|---|---|---|---|
| HR | | | | % |
| SALES | | | | % |
| FIN | | | | % |
| DEV | | | | % |
| STAFF | | | | % |
| MFG (민감 데이터 경고 없음) | | | | % |

페르소나당 응답이 5건 미만이면 **그 페르소나의 칸을 가린다**(`-`). "2명 중 1건"은 비율이 아니라 사람을 가리킨다. 파일럿(10~15명)에서는 대부분 가려지므로 `pilot.py reports`가 운영자에게만 터미널로 페르소나별 건수를 보여 주고, 운영자가 문항 검증 기록(`pilot/item-analysis.md`)에 옮긴다.

**객관식 정답률보다 이 비율이 그 조직의 거버넌스 상태를 더 정확히 말한다.** 자유 서술에서 실제로 위반을 제안한 비율이기 때문이다.

## 금지 표현 최종 검사

리포트를 내보내기 전 확인한다.

- [ ] 축별 점수·백분위가 없다
- [ ] 개인 리포트에 레이더 차트가 없다
- [ ] DEL과 FLW를 독립 스포크로 나란히 제시하지 않았다
- [ ] n < 5인 셀이 비어 있다
- [ ] 필수 문구 2개가 첫 페이지에 있다
- [ ] 개인 순위표가 없다
