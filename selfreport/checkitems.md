# 자기보고 3문항 (점수 미반영)

> **이 3문항은 점수에 반영되지 않습니다.** 앞의 문항들과 대조해 결과 해석의 정확도를 높이는 데만 사용됩니다. 편하게 사실대로 답해 주십시오.

원문의 실무 체크 질문을 그대로 쓴다. 문항 예산은 0이고 신뢰도 이득은 실질적이다.

## SR-01

**지난 한 주 동안 AI로 만든 업무 결과물을 몇 개까지 구체적으로 말할 수 있습니까?**

- [ ] 0개
- [ ] 1~2개
- [ ] 3~4개
- [ ] 5개 이상

→ 대응 축: **작업 설계(DSN)**, **검증·신뢰 조정(VER)** — 실제 사용량의 대리 지표

## SR-02

**AI를 쓰기 시작한 뒤 없어진 업무가 있습니까?** 있다면 무엇인지 한 줄로 적어 주십시오.

- [ ] 없다
- [ ] 있다 → ________________________________

→ 대응 축: **워크플로우 재설계(FLW)** — 단계 소멸

## SR-03

**다른 팀에서 AI를 잘 쓰는 사람의 이름을 댈 수 있습니까?**

- [ ] 없다
- [ ] 1명
- [ ] 2명 이상

→ 대응 축: **워크플로우 재설계(FLW)** — 전파·네트워크

## 해석 규칙

정본은 [docs/04-scoring.md](../docs/04-scoring.md)의 자기보고 삼각검증 절.

| MC 플래그 | 자기보고 | 확정 플래그 |
|---|---|---|
| 🟢 강점 신호 | 뒷받침함 | 🟢 강점 신호 |
| 🟢 강점 신호 | 뒷받침 안 함 | ⚪ 판정 보류 |
| 🟠 보완 필요 | 뒷받침함 (실사용 없음) | 🟠 보완 필요 |
| 🟠 보완 필요 | 상충 (실사용 활발) | ⚪ 판정 보류 |

**뒷받침 판정 기준**
- DSN·VER 축: SR-01이 `3~4개` 이상이면 뒷받침, `0개`면 상충
- FLW 축: SR-02가 `있다`(내용 기재) 또는 SR-03이 `1명` 이상이면 뒷받침, 둘 다 없으면 상충
- DEL·RSK 축: 대응하는 자기보고 문항이 없으므로 **MC 플래그를 그대로 쓴다**

**절대 규칙**: 자기보고로 점수를 올리거나 내리지 않는다. 플래그를 보수적으로 하향하는 방향으로만 쓴다. 조작이 쉬운 자기보고를 점수에 넣으면 진단 데이터가 오염된다.

## 조직 리포트에서의 취급

SR-02의 서술(없어진 업무)은 **조직 리포트의 정성 자료로 취합**한다. 이것이 [스폰서 합의문](../docs/09-sponsor-agreement.md) §4의 재진단 비교 지표("사라진 업무 건수")의 기준선이 된다.
